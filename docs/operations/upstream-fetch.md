# 上游订阅抓取

来源默认每 6 小时刷新，可设置为 60 秒至 31 天。来源配置版本与有效节点快照版本分别维护；列表展示最后尝试、最后成功和下次刷新时间。

抓取仅支持 HTTP / HTTPS，保留系统 TLS 证书与主机名校验。连接超时 5 秒、响应超时 30 秒、总时长 45 秒，最多跳转 3 次；压缩前和解压后的内容分别限制为 10 MiB。HTML 错误页、非 200 响应和不支持的压缩格式均返回安全错误码，不将响应正文写入日志。

每一跳先检查全部 DNS 地址，再固定本次检查的地址用于连接。默认拒绝环回、私网、链路本地、文档和其他保留地址。确实需要访问自托管内网订阅时，在部署环境设置 `UPSTREAM_PRIVATE_ALLOWLIST`，值为逗号分隔的 CIDR，例如 `10.20.30.40/32`。该授权仅由部署者配置，不允许网页输入任意白名单。

可选 `TRUSTED_OUTBOUND_PROXY_URL` 指定部署者信任的 HTTP / HTTPS 出站代理；界面通过 `default` 别名选择，不能提交任意代理地址。代理自身的 DNS、连接路由与目标解析由部署者信任和管理。新增订阅表单在已配置可信代理时默认选择它，未配置时默认直接连接；用户仍可明确选择直连。出站代理选项位于订阅地址下方，编辑已有订阅默认保持原设置。应用不继承运行环境中的通用 HTTP 代理变量。

订阅卡片显示实际保存的“连接方式”，编辑框直接选中已保存的代理别名或“直接连接”。列表只返回代理别名，不返回代理服务器地址、订阅 URL、请求头或认证信息；查看连接方式无需展开订阅凭据。新增时的默认值不会强制覆盖已有订阅的手动选择。

Clash / Mihomo 的 Fake-IP 模式可能将订阅域名解析为 `198.18.0.0/15` 中的虚拟地址。直接抓取仍拒绝该保留地址；来源选择已配置的可信代理后，允许域名的这类 DNS 结果，并将原始域名交给代理连接。IP 字面量、其他私网与保留地址仍受检查，每次重定向也重新校验。若遇到 `UPSTREAM_ADDRESS_BLOCKED`，可为来源选择可信代理，或在 Clash 的 `fake-ip-filter` 中让该订阅域名返回真实地址。

本机运行后端时，例如 Clash 的 HTTP / mixed 端口为 `7897`，可设置 `TRUSTED_OUTBOUND_PROXY_URL=http://127.0.0.1:7897`，重启后端后新增订阅会默认选择 `default`；已有订阅需在编辑页显式切换。Docker 中的 `127.0.0.1` 指向容器自身，需改用容器可达的代理地址；不要直接照搬本机地址。

订阅 URL、自定义请求头和 User-Agent 加密保存。请求头名称不区分大小写，重复项及 Host、连接控制、代理认证等保留请求头会被拒绝。跳转到不同 scheme、host 或 port 时清除全部自定义请求头并恢复默认 User-Agent，避免泄漏订阅凭据。

来源与节点列表不返回连接秘密。管理员可通过归属校验后的显式查看接口读取凭据，响应含 `Cache-Control: no-store`。编辑来源时省略秘密字段表示保留，空请求头对象表示清空；脱敏占位符不能作为新凭据保存。

接口版本号使用十进制字符串，更新须携带读取时的版本；旧版本返回 409。节点列表默认每页 50 项，最大 200 项。
