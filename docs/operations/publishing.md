# 发布和订阅链接

保存草稿不会修改订阅。校验预览也不写入数据库；“校验并发布”提交当前编辑内容，只有编译和固定版本 Mihomo 检查都成功后，才在同一个事务中保存草稿、不可变发布记录和当前发布指针。检查期间不持有数据库事务。来源或方案发生并发变化时最多重算三次；草稿版本过期返回 409，浏览器应保留当前输入并提示重新加载。

发布记录加密保存完整定义、实际使用的节点参数快照、来源版本和 YAML。历史记录不会被后续刷新改写。草稿与已发布状态用定义摘要比较，节点密码等上游参数变化引起的 YAML 摘要变化不代表存在未发布的人工编辑。

每套方案有独立的 32 字节随机令牌。数据库使用 SHA-256 查找令牌，并加密保存可恢复的原值。链接显示和下载响应均为 `Cache-Control: no-store`；下载只读取当前已保存的 YAML，不抓取上游或重新编译。重置链接后旧令牌立即返回 404；方案删除亦撤销访问。有效令牌但尚未发布时返回 409。

设置 `PUBLIC_BASE_URL` 为用户可访问的 HTTPS 地址，例如 `https://subscriptions.example.com`。链接由该设置生成，不使用浏览器提供的 Host。反向代理应关闭 `/sub/` 的访问日志或脱敏整个令牌路径，禁止缓存该路径；应用默认关闭 Tomcat 访问日志。管理接口使用会话与 CSRF，切勿把管理密码作为订阅令牌。
