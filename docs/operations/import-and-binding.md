# 完整导入、绑定与来源删除

完整 YAML 导入先生成 30 分钟预览。确认只创建新方案草稿；不会覆盖现有方案或立即发布。预览绑定当前数据版本，期间有其他变更时返回 409，需重新预览。确认后的原始 YAML 加密保留在方案的导入批次中，独立于过期预览清理。

节点、代理组、规则和规则集按内部 ID 重建引用。未知字段、类型或无法解析的引用保留在草稿和原始导入中，并列入待处理问题；解决后才能发布。HTTP 规则集的缓存路径由管理器生成。完整配置中的代理提供者不会递归下载。

只有完整连接参数（含链式代理依赖）唯一匹配时才建议关联上游。名称相同不足以匹配；多个来源参数相同也不会自动选择。所有导入节点默认保留为本地节点，关联必须显式选择。

后续绑定本地节点只修改引用它的草稿。已发布产物继续使用旧本地参数，直到再次发布。链式代理的本地依赖按需复制，避免草稿绑定改变旧发布定义。旧本地节点保留供已有发布引用，不会因绑定立即删除。

删除来源先预览影响方案，再选择：

- `KEEP_LOCAL`：当前节点转本地，保留 ID 和连接参数，组及规则继续引用。发布的来源清单更新，连接行为保持。
- `CLEAR`：移除来源节点和组成员；直接指向已删节点的规则改为 REJECT；空组保留并回退 REJECT。

两种删除都在实际内核校验后原子提交。与保存、发布或刷新竞争会返回 409，不能覆盖新数据。来源的排队或运行任务被取消，晚到的下载结果不能恢复已删来源。

所有管理接口需要登录；写入需要 CSRF。原始配置、节点参数及预览响应不缓存。订阅链接只返回最近一次成功发布的产物。
