# 手动节点维护

在 **上游订阅 → 手动节点 → 添加节点** 中录入节点，也支持一次粘贴多个节点。也可以在“统一节点池”添加节点、筛选“本地节点”，或编辑、删除已有本地节点。完整配置导入和删除订阅时保留的本地节点使用同一套维护入口。

## 按来源分组

在 **上游订阅 → 手动节点 → 管理分组** 新建来源分组，例如「自建服务器」或「朋友分享」。一个节点可以属于一个来源分组；升级前的手动节点、从完整配置保留的本地节点，以及删除上游后保留的本地节点，默认都在「未分组」。点击分组名称可以筛选，并继续按名称、协议和地区缩小范围。分组旁的数字是该组的节点总数。

- **录入新节点：** 在「添加节点」中用「保存到来源分组」选择来源。若从某个分组打开，会默认选中它；批量粘贴时，上方的选项对整批生效。导入时分组已被删除，整批都不会写入，可以重新选择并确认。
- **整理已有节点：** 勾选一个或多个节点，点击「移动到分组」并选择目标，也可以移回「未分组」。支持跨页勾选，一次最多 500 个；切换分组会清空勾选。
- **重命名或删除分组：** 在「管理分组」中操作。删除分组只会把其中节点移回「未分组」。要删除节点本身，使用列表里的「删除」或「批量删除」。

来源分组由当前账号维护，跨方案共用。例如，把「香港 01」放入「TAG」后，方案的发布预览会显示 `香港 01 · TAG`，未分组节点的后缀为 `本地节点`。移动节点、分组改名或删除后，在相关方案中点击「校验并发布」，再在 Clash Verge 更新订阅，即可看到新名称。

## 添加与编辑

在「节点地区」选择服务器地区表中的一项，或保留默认的「按节点名称自动识别」。手动指定后，改名会保留所选地区。编辑时可以改回自动识别，只修改地区时保存即可用于筛选。批量导入默认逐个识别名称，手动指定的地区会应用到整批节点。

1. 选择协议，填写名称、地址、端口和认证参数；或切换到“分享链接 / YAML”粘贴内容。添加时支持多行分享链接、Base64 订阅、Clash / Mihomo 的 `proxies:`、YAML 节点列表，以及每行一个 `{name: ..., type: ...}` 对象。
2. 常用表单支持九种现有协议；分享链接支持范围见[协议矩阵](protocol-support.md)。添加时每次最多 500 个节点、256 KiB。单节点解析后进入表单继续编辑；多个节点全部校验通过后显示名称、协议和服务器预览，点击“确认导入 N 个节点”才一次性新增。编辑已有节点仍仅接受一个节点。
3. Reality、ECH、smux、其他传输选项等在“高级 JSON”中维护，使用 Mihomo 字段名。名称、协议和链式代理分别由表单选项维护。编辑常用参数不会删除未展示的高级字段；切换协议会重置协议参数。
4. 保存前会检查字段、引用、用户归属，并执行实际 Mihomo 配置校验。失败不会部分写入，弹窗保留输入供修改。版本冲突时保留当前输入，不自动覆盖较新的数据。

节点保留同一个 ID，已配置的代理组无需重新添加。新增节点可在各方案的节点候选列表中选择；已有节点修改后，直接或通过链式代理引用它的方案都会提示待发布。

批量导入只新增，不覆盖已有同名节点；同一批次内名称必须唯一。解析、引用检查或内核校验任一失败，整批不写入。提交使用一个数据库事务，写入失败时全部回滚；输入变化、保存失败或账户数据在预览后变化时，需重新预览，避免重复提交或使用旧引用。原始文本会保留供修改。

连接参数继续加密存储；列表只返回元信息。详情和解析响应为 `Cache-Control: no-store`，关闭编辑器清除当前凭据；同账号会话恢复保留未提交输入，切换账号清除旧输入。解析在自托管服务内完成，不调用第三方转换器，不主动连接代理服务器。

## 生效时间

**保存节点只更新节点池与相关方案草稿。检查每个相关方案，校验并手动发布后，该方案的订阅链接才采用新参数。**

上游自动刷新会继续更新远程节点，但固定使用当前发布中的本地节点快照。即使连续发生多次刷新，也不会提前带入未发布的本地修改或删除。订阅链接地址保持不变。

## 删除与链式代理

删除前显示受影响草稿和已发布方案。确认后从草稿代理组中移除该节点，直接指向它的规则改为 REJECT；空组继续回退 REJECT。已发布订阅保留旧节点，直到该方案重新发布。

若其他节点还将它用作链式代理，删除被阻止，需先编辑依赖节点解除引用。确认时同时检查节点版本及账户数据版本；预览后数据有变化时，需要重新检查删除影响。

在 **上游订阅 → 手动节点** 列表中，可逐个勾选或全选当前页，再点击“批量删除”。选择会跨页保留，最多 500 个；修改搜索、协议或地区筛选条件，以及重新读取节点时清空选择。“清空选择”可随时取消全部勾选。

批量删除先列出所有待删除节点、受影响草稿和已发布方案，确认后在一个事务中全部删除；任一节点版本过期、归属不符或仍被未选中的节点依赖时，整批不删除。互相存在链式依赖的节点可以一起选择删除；未选中的直接和间接依赖会在弹窗中列出。每套受影响的草稿只更新一次，已发布订阅仍需手动发布后更新。取消弹窗保留勾选，删除成功后清空选择并重新读取列表。

链式代理可选择已有节点、DIRECT 或 REJECT，不允许循环。批量 YAML 的命名链式引用优先匹配同一批次的节点，否则必须唯一匹配当前账户节点池；不存在或有歧义时整批拒绝。编辑单节点时也可以通过表单手动选择目标。

本次不包括批量修改已有节点、测速、二维码、分享链接导出或远程订阅节点覆写。节点可达性仍由实际代理客户端验证。
